## 三、上线最小路径（建议顺序）

1. **打通网络** → 在能连到域控的机器上跑 `tools/verify_connect_wiring_live.py`（口令故意填错，到达域控被拒即为装配通）。
2. **真域写验收** → `python tools/acceptance_live.py --dc <IP> --user <域名\账号> --execute --parent-dn <专用测试OU>`，口令走 `AD_TEST_PASSWORD`，报告贴回来逐条核。
3. **打包** → PyInstaller 出 exe，在**另一台没装 Python 的机器**上双击验证（这一步专抓「依赖漏打进包」）。
4. **git init + 打 tag**，确定这一版就是基线。
5. **小范围试点** → 先用只读 + 单个 OU 的委派权限账号跑一周，再放开写权限。
