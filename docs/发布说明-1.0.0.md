# 发布说明 · v1.0.0

> 日期：2026-09-22　首个公开版本
> 附件：`bbad-1.0.0-win64.zip`（Windows 10 / 11 x64）

---

## 这是什么

一个**在没加入域的 Windows 机器上**也能用的 Active Directory 轻量管理工具，
用来替代 ADUC（`dsa.msc`）最常用的那几件事：
解锁 · 启用/禁用 · 重置密码 · 新建用户/组/计算机/组织单位 · 属性编辑 · 组策略只读查看。

双击就跑，不用装 RSAT、不用加域、不用在域控上装任何东西。

## 这一版有什么

| 分类 | 内容 |
|---|---|
| **连接** | 域控 IP/端口（可选 LDAPS）· `域\用户` 身份 · 匿名读 RootDSE 反查域名与 BaseDN · 多套连接配置 · 口令可选 DPAPI 记住 |
| **浏览** | 组织单位树（带筛选）· 对象列表（名称/类型/描述/登录名/状态/密码策略/最后登录/所属位置）· 全目录搜索 · 高级查找条件构建器 · 导出 CSV |
| **用户** | 新建 · 复制 · 重命名 · 移动 · 删除（先算影响范围）· 启用/禁用 · 解锁 · 重置密码（单个/批量）· 设置默认密码 · 登录时间网格 · 拨入页 |
| **组 / 计算机 / OU** | 新建 · 重命名 · 移动 · 删除 · 成员管理 · 启用禁用 · 重置计算机账户（域控机受保护） |
| **属性** | 常规 / 原始属性编辑器 / 对象 / 成员 / 隶属于 |
| **组策略** | **只读**：GPO 列表 · 某 OU 套了哪些 GPO · 某 GPO 链在哪些 OU · 设置摘要 · 安全筛选 |
| **运维** | 操作日志（含操作前/后值）· 强制复制同步 · 导出诊断包 · 打开配置与日志目录 · 深浅色切换 |

内置**演示模式**：没有域环境也能把整套界面点一遍，所有操作都不会碰到真实域。

## 下载与运行

1. 下载并解压 `bbad-1.0.0-win64.zip`，得到一个 `bbad\` 目录与一份 `LICENSE.txt`；
2. 双击 `bbad\bbad.exe`；
3. 在「连接」页填**域控 IP**、账号写 `域\用户`、口令，点连接。

配置与日志写在 `%APPDATA%\AD域管理工具\`，**不在 exe 同目录** —— exe 放哪都行，换台机器就是一份全新的空配置。

> 使用前请先读 `LICENSE.txt`：本软件**禁止未授权商用**，且按「现状」提供、
> 不附带任何担保。它会直接对 Active Directory 写操作，请先在测试环境验证并做好备份。

## 已知限制

* **组策略是只读的**，本版不提供任何编辑 GPO 的入口（这是有意为之，不是缺功能）。
* **「强制复制同步」在未加入域的机器上不可用** —— 它底层调用 `repadmin`，而 `repadmin` 只吃域名、不吃 IP。所以这项默认不自动执行，需要时手工点一次；点了失败也不影响已经改好的对象。
* **「记住」的口令绑本机 + 本 Windows 账号**（DPAPI）。换机器或换 Windows 账号后需要重填口令，其余连接配置不受影响。
* **禁止未授权商用** —— 完整条款见仓库根目录的 `LICENSE`（压缩包内附同一份 `LICENSE.txt`）。
